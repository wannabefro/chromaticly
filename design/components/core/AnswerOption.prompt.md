MCQ option card, 2–4 per question. Selected uses the current strand hue; correct/incorrect replace the letter badge with ✓/×. For notation answers (e.g. four key signatures) pass a mini `NotationCard` as children.

```jsx
<AnswerOption letter="A" label="1 beat" />
<AnswerOption letter="B" label="2 beats" state="selected" strand="rhythm" />
<AnswerOption letter="B" label="2 beats" state="correct" meta="correct" />
<AnswerOption letter="D" label="4 beats" state="incorrect" meta="your pick" />
```
